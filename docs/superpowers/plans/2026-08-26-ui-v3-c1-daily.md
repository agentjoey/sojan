# UI v3 · C1「桌面骨架 + 卷首 + 运势」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建起桌面「左定右动」两栏骨架，并按新设计重建卷首与运势两屏（含移动与桌面两个断点）。

**Architecture:** 先建三个共用件（两栏骨架、转盘水印、今日卡+风铃占位），再重建两个页面。页面消费 A 块的外壳原语与 B 块的命理可视化，**不新造强调手法、不在展示层推算**。

**Tech Stack:** Next.js 16 App Router · React 19 · Tailwind 4（响应式断点用类，不用 JS 判视口）· 纯 CSS keyframes · vitest + @testing-library/react（jsdom，**无布局**）

**Spec:** `docs/superpowers/specs/2026-08-26-ui-v3-c1-daily-design.md`

## Global Constraints

- **强调只有一种手法**：`components/ui.tsx` 的 `Emphasis`。**不得另造**。
- **零阴影**：`--shadow-*` 保持 `none`。桌面 hover **只允许**改 `border-color`（`line`→`line-strong`）与箭头色（`muted`→`ink`）——**不得**加投影、位移、放大（06-desktop §4）。
- **朱砂是唯一强调色**，面积 0–2%；五行五色只作命理语义。
- **不新增裸十六进制**，颜色一律用令牌名。
- **圆角上限 8px**（`--radius-chip/icon/seal` 4px、`--radius-button/card/panel` 8px），胶囊/圆钮 `9999px`。
- **展示层零推算**：候名/候序号来自 B 块的 `getCurrentSolarHou()`，流日五维/宜忌/干支来自既有 core 与 action，**组件不算**。
- **动画必须挂 CSS keyframes**，禁 JS 逐帧——`globals.css` 的 `prefers-reduced-motion` 降级块只覆盖 keyframes。
- **响应式一律用 Tailwind 断点类**，禁 `matchMedia`/`window.innerWidth`。⚠️ jsdom 测不了媒体查询生效，断言打**类名**。
- **Telegram 冻结**：`app/page.tsx` 的 `TG_ENTRIES` 分支与 `app/__tests__/page.test.tsx` 的既有断言**一个字不许改**。这是 A 块以来的红线，C1 重建首页时最容易撞。
- 基线（不许变差）：`pnpm --filter @sojan/web exec vitest run` **692**、`@sojan/core` **188**、`@sojan/llm` **279**；`pnpm exec tsc -p apps/web/tsconfig.json --noEmit 2>&1 | grep -c "error TS"` = **7**；`pnpm --filter @sojan/web run lint` = **2 errors / 17 warnings**；`pnpm --filter @sojan/web build` 通过。
