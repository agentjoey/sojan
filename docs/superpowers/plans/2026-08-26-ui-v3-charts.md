## Global Constraints

- **零阴影**：`--shadow-*` 保持 `none`，层级只靠间距 / 色调 / 1px 细线。
- **强调只有一种手法**：复用 `components/ui.tsx` 的 `Emphasis`（横向 `border-left`+`90deg`，竖向 `border-top`+`180deg`）。**不得另造**。
- **朱砂是唯一强调色**，面积 0–2%。五行五色（`--color-wood/fire/earth/metal/water`）只作命理语义，不作装饰。
- **不新增裸十六进制**。唯一例外：设计包给定的朱砂 rgba 字面值 `rgba(168,70,56,.08)`（CSS 变量无法参与 rgba 计算）。
- **圆角上限 8px**（`--radius-chip/icon/seal` 4px、`--radius-button/card/panel` 8px）。
- **展示层零推算**（仓库红线：排盘不许在展示层算）。
- ⚠️ **ARIA 陷阱（`BaguaWheel` 踩过并写进注释）**：`role="img"` 的子树对辅助技术不可见（ARIA 1.2），所以**可交互元素不能嵌在 `role="img"` 里**。纯展示的 SVG 用 `role="img"`；含可交互子元素时改用 `role="group"`，`aria-label` 保留。
- **焦点环**：可交互元素一律带 `zj-wheel-focus`（全站唯一一条 `:focus-visible` 规则）。
- 基线（不许变差）：`pnpm --filter @sojan/web exec vitest run` **671**、`@sojan/core` **178**、`@sojan/llm` **279**；`pnpm exec tsc -p apps/web/tsconfig.json --noEmit 2>&1 | grep -c "error TS"` = **7**；`pnpm --filter @sojan/web run lint` = **2 errors / 17 warnings**。

```tsx
const ORDER = [
  { element: "wood",  cn: "木" },
  { element: "fire",  cn: "火" },
  { element: "earth", cn: "土" },
  { element: "metal", cn: "金" },
  { element: "water", cn: "水" },
] as const;

const CX = 160, CY = 160, R_SECTOR = 118, R_RING = 138, R_CENTER = 50;
const START = -126, STEP = 72;

/** 极坐标 → 直角坐标。0° 指向右（东），负角逆时针向上，与上面的方位描述一致。 */
function pt(angleDeg: number, r: number) {
  const a = (angleDeg * Math.PI) / 180;
  return [CX + r * Math.cos(a), CY + r * Math.sin(a)] as const;
}

/** 整块扇形（从圆心出发）。中心圆随后覆盖上去形成环心。 */
function sectorPath(start: number, sweep: number, r: number): string {
  const [x1, y1] = pt(start, r);
  const [x2, y2] = pt(start + sweep, r);
  const large = sweep > 180 ? 1 : 0;
  return `M ${CX} ${CY} L ${x1} ${y1} A ${r} ${r} 0 ${large} 1 ${x2} ${y2} Z`;
}
```

- 每个 `<path>` 带 `data-testid="wuxing-sector"`、`data-element`、`data-start-angle`——**角度作为语义参数暴露给测试**，这样断言不依赖 path 字符串（path 字符串一改就红且毫无诊断力）。
- 扇区 `fill` 用对应五行令牌，**透明度按该五行计数占比**（计数为 0 的扇区仍然画出来，只是接近全透明——五行缺失本身是命理信息，不能不画）。

- 十天干环（r=138）：十个天干沿环等分排布，`font-serif`，`--color-muted`；日主那个天干用 `--color-cinnabar`。
- 中心圆 `r=50` 填 `--color-paper`，其上放日主天干大字（`font-serif`，`--color-ink`），容器带 `data-testid="wuxing-center"`。
