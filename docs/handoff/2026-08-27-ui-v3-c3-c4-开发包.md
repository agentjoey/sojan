## 1. 项目是什么（30 秒）

东方命理（八字 + 紫微斗数）× 西方心理占星双引擎的个人成长 App，中文名「照见」、英文 `Sojan`。核心链路：**输入出生信息 → 自动排盘 → 命理分析 + 心理分析 + 成长建议**。产品立场是把「命理预测」重构成「心理自我认知 + 成长陪伴」。

**首发市场是海外**，`detectLocale()` 对任何非中文浏览器返回 `en`——**英文是默认路径，不是边缘情况**。

Monorepo：`apps/web`（Next.js 16 App Router + React 19 + Tailwind 4）+ `packages/core`（排盘）+ `packages/llm`（解读）。

## 7. 设计系统硬约束

- **强调手法唯一**：全站只有 `Emphasis`（`apps/web/components/ui.tsx`）。**不要发明第二种**（顶边色条、背景块、投影等都算）。A 块曾因此删掉 `Card.topAccent`，C2-2 又删掉了 `ReadingTabs` 遗留的五行色顶边。
- **零阴影**：`--shadow-*` 全为 `none`。唯一例外是 `ZiweiBoard` 选中态的 `inset box-shadow`（0 模糊 0 偏移，是**描边**不是投影，且已写明理由）——**别学它新加**。
- **无裸十六进制**：一律用 CSS 令牌。
- **圆角 ≤8px**（胶囊 chip 的 `9999px` 是既有例外）。
- **朱砂是唯一强调色**。
- **hover 只允许改 `border-color` 与文字/箭头颜色**，**不得投影/位移/放大**（`06-desktop` §4）。
  ⚠️ 实心朱砂 CTA 是例外：它的 hover 反馈由 `hover:bg-cinnabar-press`（背景变深）承担。
- ⚠️ **`--color-on-ink-gold` 禁止配朱砂背景**：它在 `cinnabar` 上是 **2.58:1**、在 `cinnabar-press` 上是 **3.31:1**，均远低于 WCAG AA 4.5:1。该令牌的语境是「`--color-ink` 深色锚点上的文字」。
- **命理术语保持中文**（星曜/干支/宫名/纳音/生肖/五行/方位），两个 locale 都是。只有 UI chrome 走 `useT()`。
  ⚠️ `en.ts` 的既有约定是「**中文 (English gloss)**」，例如 `tabMingli: "命理 (Mingli)"`、`birthMutagens: "生年四化 (Natal Four Transforms)"`。新增术语类 key 照此写。

## 8. 响应式

三档断点，与 C1/C2 一致（`06-desktop` §2）：

| 断点 | 布局 |
|---|---|
| < 768px | 单列 |
| 768–1199px | 单列居中 `min(100% - 96px, 720px)` |
| ≥ 1200px | `TwoColumn` 两栏（`apps/web/components/TwoColumn.tsx`），左列宽由调用方传 |
| ≥ 1600px | 内容列上限 1120px，**不拉第三栏** |

- **一律用 Tailwind 断点类**，禁 `matchMedia` / `window.innerWidth`。
- **桌面专有样式必须断点门控**；`xl:` 与更低断点在同一属性上语义互斥处用 `max-xl:`，**不要裸 `md:`/`lg:`**。
- **两个断点共用一份 DOM 顺序**，只由 `TwoColumn` 决定落在哪列——**不要为桌面/移动各写一套**。

### ⚠️ 断点单位陷阱（本仓库踩过，代价很大）

**自定义断点一律用 rem，绝不用 px。** Tailwind 4 **无法跨单位排序** media 块——把 `--breakpoint-xl` 写成 `1200px`（其余断点是 rem）会让 xl 的 media 块被整体排到**所有 rem 断点之前**；`md:` 与 `xl:` 同属 `@layer utilities`、同特异度，**源序在后者胜出**，于是 **≥1200px 时裸 `md:` 类反而压过 `xl:` 类**。

本仓库因此让桌面两栏容器 width 从 1120px 塌成 720px、padding 归零，而**七条 class-name 断言全绿**——class-name 断言在结构上抓不到级联顺序。

现值是 `--breakpoint-xl: 75rem`（= 1200px @16px）。**不要改回 px。**

## 9. 测试与断言质量（本包最重要的一节）

三包测试全绿是**最低门槛，不是验收标准**。本仓库在 UI v3 期间连续栽在「看着测了、实际没测到」上**七次**，**本包作者自己也写出过 5 条被拦下的坏断言**。

### 9.1 七类同型缺陷（每条都真实发生过）

| # | 形态 | 真实案例 |
|---|---|---|
| 1 | 断言被同用例其他断言**完全覆盖** | 已 `toBe("#ziwei-board")` 精确断言，又加一条 `toMatch(/^#/)`——后者永无独立变红机会 |
| 2 | matcher 与实际文本**不可能匹配** | 断言里用 U+3000 全角空格，而 testing-library 只规范化元素文本、不规范化 matcher |
| 3 | **用例名承诺、断言不兑现** | 用例名「左列还渲染了四柱与大运」，断言里只有大运——**删掉四柱区块，760 条全绿** |
| 4 | 断言**过浅**（只查存在不查行为） | `expect(head.textContent).not.toBe("")`——把 `{streaming ? 提示 : "—"}` 整段挖成 `{"—"}`，12 条全绿 |
| 5 | 类型判断**恒假** | `typeof a === "string"` 用于检查 React 传给 `console.error` 的 **Error 对象** |
| 6 | 断言**维度覆盖不到失败模式** | class-name 断言抓不到 CSS 级联顺序；`className` 断言抓不到内联 `style={{transform}}` |
| 7 | 多条负例**全被同一个 `if` 拦住** | 三个非法输入长度 0/4/1，全被 `length !== 2` 拦掉，后面的查表守卫一行没测到 |

### 9.2 硬要求

1. **写每一条断言前回答**：「如果这条实现被回退，它会不会变红？」答不上来就别写。
2. **按「实现里每个分支的真假两侧」设计用例**，不要按「输入长什么样」设计。动手前先把分支列出来，逐个确认两侧都有 fixture。
3. **凡断言涉及正则/matcher，先跑一遍两侧输入验证它能区分。**
   （真实教训：`/\breading-prose\b/` 对 `"reading-prose-3c"` **也返回 true**，因为 `-` 是非单词字符——用它来验证「基类是否共存」是零区分力的。）
4. **凡断言 DOM 结构（tagName/parentElement/层级）或 CSS 是否生效，先真渲染一次打印出来看**，别凭对 JSX 的印象推断。
   （真实教训：一条 `expect(el.parentElement.tagName).not.toBe("section")` 在改动前后都通过，因为父元素两种情况下都是 `div`。）
5. **关键改动做 mutation 复验**：把实现按你要防的那种方式回退，确认**变红的正是对应那条用例**（不是别的先红），把**实际输出**写进报告。
6. **凡在注释里断言「某分支不可达」，先自己验证可达性。**
   （真实教训：一条注释称「`normalize.ts` 保证 `YYYY-MM-DD` 前缀」，但该文件拼字符串时 `year` **没有 `padStart`**，年份 <1000 时前缀会失真——**错的理由比没有注释更糟**，它让后人放心地照此推断。）
7. **jsdom 无布局**。断点/尺寸/对齐类要求断言打在**类名或样式属性**上，不是算出来的几何值。
8. **真实浏览器自查不可省**：起 dev（端口 **3030**），在 **402 / 900 / 1280** 三档各看一眼每个改过的页面，**把看到的实际现象写进报告**，不要写「符合预期」。
   ⚠️ C1 与 C2 的全分支终审各有四条 Important 是「jsdom 看不见、只有真实浏览器能发现」的版式缺陷（免责句让整页多滚 116px、页头与首元素零间距、右列顶部多余横线、块被吸进相邻块）。**这一档是同类问题唯一的拦截点。**

- **`.reading-prose` 有 8 个消费方跨 6 文件**（风水 3 处、解梦、掷筊、AskToday、当下时序、ReadingTabs）。改这个基类会波及所有页面。C2-2 的做法是加修饰类 `.reading-prose-3c`（15px/2.05 + max-width 620px）。C3/C4 若需要新排版，同样**加修饰类而不是改基类**；若你认为该统一到一处，在报告里提出、不要擅自改。
- **localStorage 键前缀 `zhaojian.*` 刻意保留旧品牌名**（`app/calendar/page.tsx`、`app/chart/page.tsx`、`lib/profiles.ts`）——改前缀等于让全体存量用户缓存失效、白烧一轮 LLM 额度。
- **`SYNTHETIC_EMAIL_DOMAIN = "zhaojian.local"`**（`apps/web/lib/access.ts`）同理刻意保留——生产库 `auth.users` 里已有真实用户邮箱是 `tg_<id>@zhaojian.local`。
- **`PillChip` / `Chip` / `Emphasis` / `Button` / `Card` 的 props 是 `Omit<…, "style">`**——传 `style` 是编译错误（刻意的护栏）。自定义样式走 `className`。
- **`ChartBlock`** 是 `app/chart/page.tsx` 的私有函数，不是共用组件；C3/C4 需要类似的「小标签 + 上细线」区块时，判断是抽公共件还是各自实现，并在报告里说明。
